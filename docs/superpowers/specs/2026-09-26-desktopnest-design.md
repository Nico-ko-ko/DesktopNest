# DesktopNest Windows 桌面收纳工具设计

日期：2026-09-26

## 目标

构建一个轻量、可固定到 Windows 任务栏的桌面收纳工具。用户可以像使用手机桌面文件夹一样，把桌面快捷方式拖入工具，双击启动其中保存的软件，并通过右键进行重命名或移出。

程序必须在关闭并重新打开后恢复工具名称、窗口位置和收纳内容，并且不依赖用户安装额外运行环境。

## 技术方案

- 使用 C# 和 WinForms 开发。
- 目标运行时为 Windows 自带的 .NET Framework 4.8。
- 使用系统自带 C# 编译器构建，发布为单个绿色版 `.exe`。
- 设置专用 AppUserModelID，使固定到任务栏的项目显示 DesktopNest 自己的名称和图标。
- 使用单实例互斥锁。重复启动时，将已有主窗口显示到前台。
- 不使用 Electron、WPF、第三方 NuGet 包或安装程序。

## 界面与交互

### 主窗口

- 使用标准 Windows 可调整大小窗口，默认尺寸约为 `640 × 420`。
- 支持最小化、关闭、调整大小和任务栏固定。
- 标题栏显示工具名称。
- 双击标题名称可就地修改名称。
- 主区域使用可滚动图标网格，并根据窗口宽度自动调整列数。

### 图标项

- 从系统原文件提取图标。
- 图标下方显示收纳项名称，文字过长时省略，并在悬停提示中显示完整名称。
- 双击启动收纳的软件。
- 悬停时显示高亮状态。
- 右键菜单包含“打开”“重命名”“移出收纳”。

### 空白区域

- 支持将桌面快捷方式直接拖入窗口。
- 右键菜单包含“从文件添加”和“打开数据目录”。
- 空列表显示简洁的拖入提示。

### 接受的拖入类型

- `.lnk` 快捷方式：复制到工具数据目录。
- `.exe` 可执行文件：创建指向原文件的快捷方式并保存到工具数据目录。
- `.url` Internet 快捷方式：复制到工具数据目录。
- 文件夹：创建指向该文件夹的快捷方式并保存到工具数据目录。
- 其他普通文件：创建指向该文件的快捷方式并保存到工具数据目录。

## 数据设计

数据根目录为 `%LOCALAPPDATA%\DesktopNest`。

```text
%LOCALAPPDATA%\DesktopNest\
  data.json
  items\
    <唯一标识>.lnk
    <唯一标识>.url
```

`data.json` 保存：

- 数据格式版本。
- 工具名称。
- 窗口位置和尺寸。
- 窗口最大化状态。
- 收纳项唯一标识。
- 收纳项显示名称。
- 保存后的快捷方式文件名。
- 收纳项顺序。
- 可选的目标路径提示，用于显示失效原因。

写入采用以下流程：

1. 将新内容写入同目录临时文件。
2. 刷新并关闭临时文件。
3. 使用替换操作覆盖 `data.json`。
4. 写入失败时保留原文件并显示错误提示。

所有程序数据不写入程序所在目录，因此程序可以移动，已有收纳内容不会丢失。

## 组件边界

### Program

- 解析启动参数。
- 初始化应用数据目录。
- 执行单实例控制。
- 执行隐藏自检模式。
- 启动主窗口。

### AppSettingsStore

- 定义和序列化 `AppSettings`。
- 读取和原子写入 `data.json`。
- 对缺失文件、损坏 JSON 和不兼容版本提供恢复行为。

### ShortcutImporter

- 识别拖入文件类型。
- 复制现有快捷方式，或通过 Windows Shell 创建快捷方式。
- 生成唯一标识。
- 返回收纳项元数据。
- 在失败时返回可读错误，不修改设置。

### ShortcutLauncher

- 通过 Windows Shell 打开快捷方式。
- 在目标不存在或启动失败时提供错误结果。

### IconService

- 提取 `.lnk` 目标、`.exe`、`.url` 或普通文件的系统图标。
- 将图标转换为 WinForms 可绘制对象，并缓存结果。

### MainForm

- 绘制标题、网格和空状态。
- 处理拖放、双击、右键菜单和改名。
- 根据配置创建和刷新图标项。
- 保存窗口位置、尺寸和列表变化。

### SettingsModel

- 保存纯数据模型。
- 不依赖窗口或磁盘实现，便于自检。

## 数据流

### 启动

1. 创建数据目录。
2. 读取 `data.json`。
3. 验证收纳项对应文件是否存在。
4. 恢复工具名称、窗口大小和位置。
5. 绘制图标网格。

### 拖入

1. 窗口接收文件列表。
2. 对每个文件执行类型识别和快捷方式保存。
3. 生成收纳项并追加到列表。
4. 写入 `data.json`。
5. 刷新网格；某一项失败时保留其他成功项并报告失败原因。

### 启动收纳项

1. 双击或从右键菜单选择“打开”。
2. 解析保存在数据目录中的快捷方式。
3. 调用 Windows Shell 启动。
4. 失败时显示错误提示，不删除收纳项。

### 移出

1. 从列表中移除收纳项。
2. 删除工具数据目录中的快捷方式副本。
3. 原子写入 `data.json`。
4. 刷新网格。
5. 不修改桌面原快捷方式。

## 错误处理

- `data.json` 不存在：创建默认配置。
- `data.json` 损坏：重命名为带时间戳的备份文件，创建默认配置，并提示用户。
- 快捷方式副本丢失：保留收纳项并标记为失效，允许移出或重新添加。
- 目标程序不存在：显示“目标已不存在”，不自动删除收纳项。
- 拖入不支持的内容：说明支持类型，不产生配置变更。
- 重名：允许显示名称重复，但内部文件使用唯一标识，避免覆盖。
- 数据目录无写权限：显示数据目录路径和失败原因。
- 异常关闭：原子写入保证至少保留上一份有效配置。

## 窗口持久化

- 关闭时保存工具名称、窗口尺寸、位置、最大化状态和收纳项顺序。
- 恢复前检查窗口是否仍位于当前可见桌面范围内；如果不在，则移回主屏幕。
- 最小化状态不持久化，下次启动恢复为普通可见窗口。

## 安全与隐私

- 不扫描桌面，不监控用户文件，不联网。
- 只处理用户主动拖入或通过对话框选择的文件。
- 不读取快捷方式之外的文档内容。
- 不修改桌面原快捷方式，也不移动原程序文件。

项目包含：

- 源码。

## 验证方案

### 自动自检

程序提供 `--self-test` 隐藏参数，验证：

- 默认设置创建。
- 设置序列化和反序列化。
- 原子写入后重新读取一致性。
- 唯一标识生成。
- 收纳项添加和移除。
- 损坏 JSON 的备份和恢复。
- 窗口坐标归一化。

自检失败时返回非零退出码并输出可读原因。

### 实际运行验证

1. 启动 `DesktopNest.exe`，确认主窗口出现且没有控制台窗口。
2. 从桌面拖入一个 `.lnk` 快捷方式，确认图标出现。
3. 双击收纳项，确认对应软件启动。
4. 右键重命名收纳项，确认显示名称改变。
5. 右键移出收纳项，确认桌面原快捷方式不受影响。
6. 修改工具名称，调整窗口位置和大小，然后关闭并重新启动。
7. 确认名称、位置、尺寸和收纳内容均已恢复。
8. 重复启动程序，确认只保留一个实例并唤醒原窗口。
9. 固定程序到任务栏，确认图标和名称正确，点击后能启动。

## 验收标准

- 工具可以双击打开。
- 桌面图标可以拖入窗口。
- 双击收纳项可以直接启动对应软件。
- 收纳项可以通过右键移出。
- 工具名称和收纳内容可以修改并持久保存。
- 窗口位置和尺寸在下次启动时恢复。
- 程序可以固定到任务栏，并使用自己的图标和名称。
- 整个程序无需管理员权限和额外运行时安装。

## 非目标

- 不管理、移动或删除桌面原快捷方式。
- 不扫描或自动导入整个桌面。
- 不提供云同步、账号、网络更新或遥测。
- 不提供安装包。
- 不支持开机自动启动。
- 不提供跨设备同步。
